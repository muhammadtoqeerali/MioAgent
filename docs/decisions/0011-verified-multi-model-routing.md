# ADR 0011 — Local-only benchmark-verified multi-model role routing

Status: Implemented in v0.4D. Decision: installed Ollama SHA-256 identities, explicit owner activation of a native 0600 JSON policy, bounded three-candidate sequential fallback by role, immutable acceptance-test authority in Project Mode, and an advisory lock for fleet-managed GPU load. Existing single-model behavior remains if policy is absent. No cloud/model pull by default. Format probes guide priorities but never establish frontier coding equivalence. Independent review is advisory, not a verifier. Unmanaged Ollama clients and preexisting model route config are outside the fleet lock scope; no claim to global GPU isolation. Local project creation remains explicitly operator-authorized; source changes remain reviewed and limited by existing sandbox policies.
